# اسنپ مشترک — همسفریاب دانشجویی کیش

> ⚠️ **پروتوتایپ / نسخه تستی** — هنوز در مرحله آزمایش است.

وب‌اپ سبک برای هماهنگی سفرهای اشتراکی دانشجویی (ثبت سفر، پیوستن به سفر، کیف پول توکنی و امتیازدهی به هم‌سفرها).

## ساختار
- `index.html` — رابط کاربری (تک‌صفحه‌ای)
- `api.php` — API سمت سرور (PHP + MySQL)
- `schema.sql` — ساختار دیتابیس
- `config.example.php` — نمونه تنظیمات دیتابیس

## راه‌اندازی روی هاست
1. یک دیتابیس MySQL بسازید و `schema.sql` را در phpMyAdmin اجرا کنید.
2. `config.example.php` را به `config.php` کپی کنید و اطلاعات دیتابیس را وارد کنید (این فایل در گیت نادیده گرفته می‌شود).
3. فایل‌ها را روی هاست آپلود کنید و `index.html` را باز کنید.
4. پس از ثبت‌نام اولین کاربر، با دستور آخر `schema.sql` او را ادمین کنید.
